# Usage

Usage shows raw token cost and processed tokens scanned from the provider CLIs on
each connected environment — Claude Code, Codex, and Grok. Turns you ran outside
T3 Code still count, as long as their transcripts are on that machine.

Open **Usage** from the sidebar. Pick a 7-, 30-, or 90-day window, then switch
the chart between cost and tokens.

## Filters

- **Provider.** Tap Codex, Claude Code, or Grok next to the chart to hide or
  show that series. Totals, the chart, and the breakdown all follow the same
  selection.
- **Model.** Use the model menu to include only some models, or tap a row in
  the model breakdown to isolate it. Tap the same row again, or choose
  **Show all models**, to clear the filter.

Cost figures are the API-equivalent price of the tokens, not what a
subscription billed. Grok's own per-turn cost is used when the transcript
includes it.

On mobile the same filters live on the provider chips and the **By model** list.
