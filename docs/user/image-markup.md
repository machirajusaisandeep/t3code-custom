# Mark up an image

Paste or drop any image into the composer — a screenshot, mock, photo, or export — then click the thumbnail and choose **Draw**.

The markup editor lets you:

- Draw freehand, arrows, or boxes
- Drop numbered pins on a specific control
- Type a short label on the image
- Crop to the region that matters

Apply writes the marks into the image itself. The agent sees the highlighted image, which is the reliable way to point at one button or label on a large page.

Markup is available in the web and desktop composers. Native mobile does not include the editor yet.
